# Security Policy

## Supported Versions

uni-verein is developed as a rolling-release project. Only the **latest released
version** is supported with security fixes. If you're running an older version,
please [update](README.md#updating) before reporting an issue that may already
be fixed.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, use GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/uni-verein/uni-verein/security) of this
   repository.
2. Click **"Report a vulnerability"** to open a private advisory.

This keeps the report visible only to you and the maintainers until a fix is available,
and lets us coordinate a fix and disclosure directly with you through GitHub.

### What to include

To help us understand and reproduce the issue quickly, please include:

- A clear description of the vulnerability and its potential impact
- Steps to reproduce it (a minimal example is ideal)
- The affected version/commit
- Any relevant logs, screenshots, or proof-of-concept code

### What to expect

This is a small, mostly solo-maintained open source project, so response times are
best-effort rather than guaranteed under an SLA. We aim to:

- Acknowledge new reports as soon as we can
- Investigate and keep you updated on progress
- Credit you in the advisory/release notes once fixed, if you'd like

We ask that you give us a reasonable amount of time to investigate and release a fix
before any public disclosure, and that you avoid accessing, modifying, or deleting other
users' data while investigating.

Thank you for helping keep uni-verein and its users safe.
